# 大厅查询十六进制 ID 支持

## 意图

大厅查询输入支持用户常见的无前缀十六进制 Steam Lobby ID，并在前端转换为后端现有接口要求的十进制字符串。

## 规则

- 去除首尾空白。
- 恰好 18 位且全部为数字时，按十进制直接提交。
- 其他全部由十六进制字符组成的非零输入，按十六进制转换为十进制后提交。
- 转换结果必须为非零、且不超过 `ulong` 最大值。
- 空输入、零值、非法字符和溢出输入拒绝提交，并显示输入错误。

## 兼容性边界

- 后端 API、查询结果结构和加入 URI 保持不变。
- 现有 18 位十进制大厅 ID 的请求值保持不变。
- 十六进制输入只在前端归一化，不改变服务端数据。

## 验证

组件测试验证十六进制示例 `186000067116ec9` 转换后调用查询函数，18 位十进制保持原值，短纯数字按十六进制处理，非法输入不发起请求。
